# Guillotine elimination odds snapshot

A static ESPN Fantasy guillotine dashboard snapshot. The site displays this week's ESPN projections and modeled chances of finishing as the lowest-scoring active team.

This snapshot was generated locally. It does not contain ESPN session credentials and does not fetch private ESPN data from the browser. It is a point-in-time snapshot and can become stale when projections or lineups change.

The probabilities use a provisional position-level score-variance model, so they are estimates rather than calibrated guarantees.
